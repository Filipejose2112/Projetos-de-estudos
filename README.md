# 📚 Meus Projetos de Estudos (Python)

Bem-vindo ao meu repositório de aprendizado! Aqui eu centralizo os sistemas que desenvolvi do zero para praticar lógica de programação, manipulação de dados e interações via terminal no Python.

---

## 🛠️ Projetos Inclusos

### 1. Sistema Bancário (`Sistema_Login_Cadastro.py`)
- **O que faz:** Simula a entrada em uma conta corrente. Conta com criação de novos usuários, validação de segurança de senha (mínimo de 6 caracteres), tratamento para campos vazios e checagem de credenciais no login.

### 2. O Restaurante (`Restaurante.py`)
- **O que faz:** Gerencia um sistema de pedidos de comidas e bebidas com controle automático de estoque e proteção contra erros. Apresenta o cardápio, calcula as contas separadamente por categoria, reduz os itens do inventário de forma dinâmica e exibe um resumo inteligente usando contagem de listas antes de processar o pagamento.

### 3. Simulador de Hortifrúti (`hortifruti.py`)
- **O que faz:** Um sistema completo de feira focado em um carrinho de compras altamente dinâmico. O usuário conta com um menu interativo para adicionar produtos, alterar a quantidade total de um item diretamente na estrutura do dicionário ou remover produtos completamente antes de fechar o valor final. 

---

## 🚀 Conceitos Chave Praticados nos Códigos

- **Estruturas de Dados:** Uso prático de listas (`list`), dicionários (`dict`) e conjuntos únicos (`set`) para otimizar buscas e contagens.
- **Controle de Fluxo:** Loops infinitos controlados (`while True`), interrupções (`break`), desvios (`continue`) e verificações complexas de associação (`in` / `not in`).
- **Tratamento de Exceções:** Aplicação de blocos `try/except` para impedir o travamento dos programas por erros de digitação (como inserir letras no campo de quantidade).
