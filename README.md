# 📚 Meus Projetos de Estudos (Python)

Bem-vindo ao meu repositório de aprendizado! Aqui eu centralizo os sistemas que desenvolvi do zero para praticar lógica de programação, manipulação de dados e interações via terminal no Python.

---

## 🛠️ Projetos Inclusos

### 1. Sistema Bancário Completo (`Banco.py`)
- **O que faz:** Simula de forma robusta caixas eletrônicos reais. Possui controle de login dinâmico, verificação e bloqueio de dados incorretos e um setor financeiro integrado e protegido por `try/except` para operações de depósitos, saques e consultas de saldos.

### 2. O Restaurante SHIRIAOSNAIAH (`Restaurante.py`)
- **O que faz:** Gerencia um sistema de pedidos de comidas e bebidas com controle automático de estoque e proteção contra erros. Apresenta o cardápio, calcula as contas separadamente por categoria, reduz o inventário em tempo real e exibe um resumo inteligente usando conjuntos (`set`) para contar os itens antes de processar o pagamento.

### 3. Simulador de Hortifrúti (`Horitfruti.py`)
- **O que faz:** Um sistema focado em um carrinho de compras altamente maleável. O usuário conta com um menu interativo para adicionar produtos, alterar a quantidade total de um item diretamente na estrutura do dicionário ou remover produtos completamente antes de fechar o valor final.

### 4. Sistema de Cadastro e Rede Social (`Sistema_Login_Cadastro.py`)
- **O que faz:** Simula uma interface de rede social. Possui sistema seguro de cadastro, loops exclusivos para validação de tamanho de senha, login integrado com comparação direta (`==`) e menus internos (aninhados) para navegar no perfil do usuário e alterar senhas.

---

## 🚀 Conceitos Chave Praticados nos Códigos

- **Estruturas de Dados:** Uso prático de listas (`list`), dicionários (`dict`) e conjuntos únicos (`set`) para otimizar buscas e contagens.
- **Controle de Fluxo:** Loops infinitos controlados (`while True`), interrupções (`break`), desvios (`continue`) e funções que retornam dados dinâmicos (`return`).
- **Tratamento de Exceções:** Aplicação de blocos `try/except` para impedir o travamento dos programas por erros de digitação (como inserir letras no campo de quantidade e valores em dinheiro).

---

## 💻 Como Executar

Escolha o arquivo do projeto que deseja testar e execute o comando correspondente no seu terminal:

💡 Nota: Certifique-se de ter o Python instalado na sua máquina e de estar com o terminal aberto na mesma pasta onde os arquivos foram baixados.

```bash
# Para testar o Sistema Bancário XYZ
python Banco_XYZ.py

# Para testar o Restaurante SHIRIAOSNAIAH
python Restaurante.py

# Para testar o Simulador de Hortifrúti
python Hortifruti.py

# Para testar a Rede Social / Cadastro
python Sistema_Login_Cadastro.py
